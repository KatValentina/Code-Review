
## Задание №1  Стек: добавление элемента и вывод адреса новой вершины
---
### Цель:
Дано число D и указатель P1 на вершину непустого стека. 
Добавить элемент со значением D в стек и вывести адрес P2 новой вершины стека. 
Структура «стек» моделируется цепочкой связанных узлов типа TNode, вершиной считается первый элемент цепочки.
### Алгоритм:
1. Инициализация стека с указателем top, равным nullptr для пустого стека.
2. Интерактивное меню с вводом данных с клавиатуры: добавление, удаление, вывод, очистка стека, выход.
3. Добавление элемента (push): создание нового узла TNode, установка его поля next на текущую вершину, обновление top.
4. Удаление элемента (pop): сохранение указателя на вершину, сдвиг top к следующему узлу, освобождение памяти.
5. Дружественная функция add_element_and_print_address добавляет элемент со значением D и выводит адрес новой вершины через get_top().
6. Очистка стека (clear_stack): последовательное удаление всех узлов до обнуления top.
7. Деструктор ~Stack() вызывает clear_stack() для освобождения памяти при уничтожении объекта.

### Исправления (FIX_ME)
1. Убрана директива using namespace std в соответствии с Google Style Guide.
2. Имя типа узла приведено к TNode в соответствии с условием задачи (вместо Node).
3. Переименованы методы и функции в соответствии с правилом lower_case_with_underscores.
4. Добавлен деструктор ~Stack() для освобождения динамической памяти.
5. Классы и методы разделены по файлам: объявления — в Header.h, реализации — в отдельном .cpp.
6. Добавлена установка локали setlocale(LC_ALL, "russian") для корректного вывода кириллицы.
7. Добавлены проверки корректного ввода: при чтении пункта меню и добавляемого значения.

## Задание №2 Очередь: разделение чисел по позициям
---
### Цель:
Реализовать структуру данных «очередь» на базе односвязного списка и с её помощью 
разделить 10 введённых пользователем чисел на две очереди: 
1.  числа, стоящие на нечётных позициях
2. числа, стоящие на чётных  
Также необходимо реализовать вывод обеих очередей.
### Алгоритм:
1. Описание структуры узла.
2. Реализация класса Queue с приватными полями.
3. Описание методов и функций, необходимых для рабты с очередью.
4. В функции main организуется ввод 10 чисел с клавиатуры с проверкой корректности.
5. Числа на нечётных позициях добавляются в первую очередь, на чётных — во вторую.
6. Вывод содержимого и указателей для обеих очередей.
7. Освобождение памяти выполняется деструктором, который последовательно удаляет все узлы.
### Исправления (FIX_ME)
1. Убрана директива using namespace std в соответствии с Google Style Guide.
2. Использованы полные имена из пространства std.
3. Переименованы классы и структуры в CamelCase, методы и переменные — в lower_case_with_underscores.
4. Добавлен деструктор для корректного освобождения динамической памяти.
5. Добавлены проверки на:
	+ корректность ввода данных с клавиатуры
	+ пустую очередь при удалении элемента
	+ корректность вывода указателей при пустой очереди (nullptr)
6. Код разделён по файлам: объявления — в Header.h, реализации — в отдельном .cpp.

4. Вывод элементов списка в порядке их расположения (от большего к меньшему).
5. Освобождение памяти, занятой всеми узлами списка, в деструкторе.
