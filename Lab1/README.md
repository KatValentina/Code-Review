
## Задание №1 Артефакты и минимальное налоговое бремя
---
### Цель:
Найти такое подмножество из N артефактов, 
чтобы их суммарный вес был больше Z кг, а суммарное 
налоговое бремя было минимальным. Необходимо вывести 
номера выбранных артефактов, их суммарный вес и общее налоговое бремя.
### Алгоритм:
1. Считывание количества артефактов N и их характеристики (вес и налоговое бремя).
2. Проверка корректности входных данных и открытия файла.
3. Вычисление суммарного веса всех артефактов и проверка возможности набрать необходимый вес.
4. Использование алгоритма динамического программирования для нахождения подмножества артефактов с минимальным налоговым бременем при условии, что суммарный вес превышает Z кг.
	+ dp[w] хранит минимальное налоговое бремя для получения суммарного веса w;
	+ used[w] хранит информацию о выбранных артефактах;
	+ для каждого артефакта проверяется возможность добавить его к уже существующему весу.
5. Поиск минимального налогового бремени среди вариантов, вес которых превышает z
6. Восстановление выбранных артефактов по массиву used
7. Вывод номеров выбранных артефактов, их суммарного веса и общего налогового бремени.

## Задание №2 Артефакты и минимальное налоговое бремя
---
### Цель:
Найти минимальную сумму чисел при движении «черепашки» от
левого нижнего угла до верхнего правого, двигаясь только вверх и вправо.
### Алгоритм:
1. Считывание размера доски n и её элементов из входного файла a.txt.
2. Проверка корректности открытия файла и считывания входных данных.
3. Проверка размера доски n в соответствии с условием задачи.
4. Проверка каждого элемента доски: значение должно находиться в диапазоне от 0 до 100.
5. Динамическое программирование:
	+ dp[i][j] хранит минимальную сумму на пути от левого нижнего угла до клетки (i, j);
	+ для каждой клетки рассматриваются два возможных направления движения — снизу и слева;
	+ для каждой клетки рассматриваются два возможных направления движения — снизу и слева;
выбирается минимальная из возможных сумм.
6. Начальным состоянием является левая нижняя клетка:
dp[n - 1][0] = b[n - 1][0].
7. После заполнения таблицы минимальная сумма находится в правом верхнем углу dp[0][n - 1].
8. Результат записывается в выходной файл b.txt.
9. На экран выводится сообщение о том, что результат был записан в файл.

4. Добавлены проверки на:
	+ корректность входных данных условиям
	+ открытие и считывание параметров из файла

Определить количество N-разрядных чисел в системе счисления с основанием K, в записи 
которых содержится два или более подряд идущих нуля.
### Алгоритм:
1. Считывание основания системы счисления k и количества разрядов n с клавиатуры.
2. Проверка корректности введённых значений:
3. Использование динамического подсчёта количества чисел по состояниям:
	+ non_zero — количество чисел, последняя цифра которых не равна нулю и в которых ещё нет двух подряд идущих нулей;
	+ one_zero — количество чисел, заканчивающихся одним нулём;
	+ two_or_more_zeros — количество чисел, содержащих два или более подряд идущих нуля.	
4. На каждом следующем разряде сохраняются предыдущие значения состояний.

6. После обработки всех n разрядов результатом является значение two_or_more_zeros.
7. Результат выводится на экран в виде вещественного числа.
